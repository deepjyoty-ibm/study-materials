| [Authentication Issues](Authentication-Issues.md) | You see 401/403 or `CredentialUnavailableException`. | 📝 |
| [Dependency Injection Issues](Dependency-Injection-Issues.md) | The host fails to start or a service cannot be resolved. | 📝 |
| [Configuration Issues](Configuration-Issues.md) | Settings are missing, wrong or not binding. | 📝 |

| [Deployment Issues](Deployment-Issues.md) | Deployment succeeds but functions are missing or fail to start. | 📝 |
